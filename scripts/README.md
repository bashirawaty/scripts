# scripts

Collection of small, well-tested, secure scripts and utilities.

Quickstart

- Initialize locally:
  git init
  git add .
  git commit -m "Initial commit"
  git branch -M main
- Create repo and push (GitHub CLI):
  gh repo create <OWNER>/scripts --public --source=. --remote=origin --push

Security & CI
- Dependabot for dependency updates
- CodeQL scanning
- Super-Linter for linting
- Branch protection & required reviews
